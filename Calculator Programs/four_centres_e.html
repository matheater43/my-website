Program Logic

Write $A = (a_1, a_2)$, $B = (b_1, b_2)$, $C = (c_1, c_2)$.

Centroid

Centroid $G = \left( \dfrac{a_1 + b_1 + c_1}{3}, \dfrac{a_2 + b_2 + c_2}{3} \right)$
Since $G = \dfrac{A + B + C}{3}$, $A = 3G - B - C$.

Orthocentre

For the orthocentre $H$, $\arg(D)$ and $\arg(X)$ are the inclinations of $AC$ and $BC$ respectively.
Since the arguments sum when complex numbers multiply, \begin{align*} \arg(i D \div X) = \arg(i) + \arg(D) - \arg(X) = 90^\circ - \angle ACB \end{align*}
\begin{align*} \tan[\arg(i D \div X)] = \tan(90^\circ - \angle ACB) = \frac{1}{\tan \angle ACB} \end{align*} Since $iY$ is perpendicular to $AB$, it is a direction vector for $\overrightarrow{CH}$.
So we need to add a certain multiple $k$ of $iY$ to $C$ to get $CH$.
To see why $k = \tan[\arg(i D \div X)]$, first note that $\angle ECH = 90^\circ - \angle BAC = \angle ABE$. Then, \begin{align*} \tan \angle ACB = \frac{BE}{CE} = \frac{AB \cos \angle ABE}{CH \cos \angle ECH} = \frac{AB}{CH} \Rightarrow CH = \frac{AB}{\tan \angle ACB} = AB \tan[\arg(i D \div X)] \end{align*} Since the length of $iY$ is $AB$, multiplying it by $\tan[\arg(i D \div X)]$ gives the vector $\overrightarrow{CH}$.
In the backwards case, if $H$ is the orthocentre of $\Delta ABC$, then $A$ is the orthocentre of $\Delta BCH$, so the same code can be used.

Circumcentre and the radius of the circumcircle

For the circumcentre $K$, we need the following fact: \begin{align*} \overrightarrow{KA} + \overrightarrow{KB} + \overrightarrow{KC} = \overrightarrow{KH} \quad ......(*) \end{align*} Since $\overrightarrow{CH} + \overrightarrow{KC} = \overrightarrow{KH}$, it suffices to show that $\overrightarrow{CH} = \overrightarrow{KA} + \overrightarrow{KB}$.
First observe that $\overrightarrow{KA} + \overrightarrow{KB} = 2\overrightarrow{KM}$ is a vector perpendicular to $AB$, i.e. parallel to $CH$. \begin{align*} (x + z) + (x + y) + (y + z) &= 180^\circ \\ 2(x + y + z) &= 180^\circ \\ x + y + z &= 90^\circ \end{align*} \begin{align*} 2KM = 2BM \tan x = AB \tan x = AB \times \frac{1}{\tan(90^\circ - x)} = AB \times \frac{1}{\tan(y + z)} = AB \times \frac{CE}{BE} \end{align*} Recall $\dfrac{BE}{CE} = \dfrac{AB}{CH} \Rightarrow \dfrac{AB}{BE} \times CE = CH$, so $CH = 2KM$ as expected.
Now from ($*$), \begin{align*} (\overrightarrow{OA} - \overrightarrow{OK}) + (\overrightarrow{OB} - \overrightarrow{OK}) + (\overrightarrow{OC} - \overrightarrow{OK}) &= \overrightarrow{OH} - \overrightarrow{OK} \\[1mm] \overrightarrow{OA} + \overrightarrow{OB} + \overrightarrow{OC} &= \overrightarrow{OH} + 2\overrightarrow{OK} \\[1mm] \overrightarrow{OK} &= \frac{1}{2}(\overrightarrow{OA} + \overrightarrow{OB} + \overrightarrow{OC} - \overrightarrow{OH}) \end{align*} The radius of the circumcircle is the distance between the circumcentre and any one of the vertices, e.g. $AK$.

Incentre and the radius of the inscribed circle

For the radius of the inscribed circle, we use the formula: \begin{align*} r = \frac{2A}{P} \end{align*} where $P = \text{perimeter of the triangle} = |D| + |X| + |Y|$ and $A = \text{area of the triangle}$, which is found by the shoelace formula.
For the incentre $I = (x, y)$, we use the formula: \begin{align*} x = \frac{a x_A + b x_B + c x_C}{a + b + c}, \quad y = \frac{a y_A + b y_B + c y_C}{a + b + c} \end{align*} where $A = (x_A, y_A)$, $B = (x_B, y_B)$, $C = (x_C, y_C)$, $a = BC$, $b = AC$ and $c = AB$.
So, \begin{align*} I &= \frac{aA + bB + cC}{a + b + c} \\[1mm] &= \frac{(a + b + c)C + (A - C)a + (B - C)b}{a + b + c} \\[1mm] &= C + \frac{D|X| + X|D|}{|D| + |X| + |Y|} \end{align*} Now suppose $A$ is the incentre. \begin{align*} \text{Abs}((A - C)\sin(\arg(D)) = AC \sin \angle ACE = AE = \text{radius of the inscribed circle} \end{align*} Note that \begin{align*} 2(\angle ACB + \angle ABC + \angle APE) &= 180^\circ \\ \angle ACB + \angle ABC + \angle APE &= 90^\circ \end{align*} So, \begin{align*} \text{Abs}(A - C)\cos(\arg(D)) + \text{Abs}(\text{Ans} \tan(\arg(D \div X))) &= AC \cos \angle ACE + AE \tan(\angle ACB + \angle ABC) \\ &= CE + AE \tan(90^\circ - \angle APE) \\ &= CE + AE \tan \angle PAE \\ &= CE + EP \\ &= CP \end{align*} The argument of $\overrightarrow{CP}$ is the argument of $AC - \angle ACB$.

Example 1

The coordinates of $A$, $B$ and $C$ are $(4, 3)$, $(0, 0)$ and $(4, 0)$ respectively. Find the coordinates of the centroid, orthocentre, circumcentre and incentre of $\Delta ABC$.

$4+3i$   EXE / input coordinates of the 1st vertex in complex form
$0$   EXE / input coordinates of the 2nd vertex in complex form
$4$   EXE / input coordinates of the 3rd vertex in complex form
/ $\dfrac{8}{3}+i$ centroid $=\left(\dfrac{8}{3},1\right)$
EXE $4$ orthocentre $=(4,0)$

EXE $3+i$ incentre $=(3,1)$
