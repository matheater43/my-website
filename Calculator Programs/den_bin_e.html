Interconversion between bases 2 and 10

Basic Information

Mode:
3 BASE
Memory:
61 Bytes
Reference: hhttps://www.youtube.com/watch?v=czotqTj_ST4 (with minor modifications)
Modification:
    Uses ‘If’ instead of ‘Goto’
Usage:
  • Converts a denary number into a binary number (up to 16 digits)
  • Converts a binary number (up to 16 digits) into a denary number

Examples

Example 1 DSE 2015 (II) Q33

Convert $3147_{10}$ into a binary number.
Keying sequence Display Meaning
$1$   EXE / $1\Rightarrow$ input in base 10
$0\Rightarrow$ input in base 2
$3147$   EXE / input number in base 10
/ $1100$ number in base 2 begins with $1100$
/ $1001011$ remaining 8 digits is $1001011$ (omitting leftmost zeros)
$\thus 3147_{10}=110001001011_2$

Example 2 DSE 2026 (II) Q31

Convert $1010100000001110_{2}$ into a denary number.
Keying sequence Display Meaning
$0$   EXE / $1\Rightarrow$ input in base 10
$0\Rightarrow$ input in base 2
$10101000$   EXE / input number in base 2 without the rightmost 8 digits
$1110$   EXE / input the rightmost 8 digits (omitting leftmost zeros)
/ $43022$ number in base 10 is $43022$
$\thus 1010100000001110_{2}=43022$
